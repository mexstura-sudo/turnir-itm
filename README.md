# Турнир по информатике ИТМ

Сайт турнира Иркутского техникума машиностроения им. Н. П. Трапезникова.

- `index.html` — олимпиада: 10 заданий, одна попытка на участника.
- `game.html` — игра «Захват сети ИТМ», 9–13 ноября (вход по коду, который выдаётся после олимпиады).
- `admin.html` — пульт организатора (нужен ключ).

Задания и проверка ответов хранятся на сервере (Supabase), в этом репозитории ответов нет.
